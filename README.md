## 🌟 Visão Geral

**SVP ACADEMIC HUB** é um hub centralizado que agrupa **6 aplicações educacionais poderosas** em um único ponto de acesso. Cada ferramenta é totalmente independente mas integrada ao hub através de uma interface profissional com sidebar expansível, central de ajuda, configurações personalizáveis e guias interativos.

### ✨ Destaques Principais

- 📚 **6 Ferramentas Acadêmicas**: Cada uma com propósito específico
- 🎨 **Interface Unificada**: Sidebar expansível com emojis e nomes
- 📐 **Abas de Teoria**: Conteúdo matemático/científico estruturado
- 📖 **Guias Interativos**: "Como Usar" passo a passo para cada app
- 🌓 **Tema Dark/Light**: Personalizável em tempo real
- 🖼️ **Posters Visuais**: Cada ferramenta com arte própria
- 📚 **Central de Ajuda**: Acesso rápido a todas as documentações
- ⚙️ **Configurações**: Tamanho de fonte (pequeno/médio/grande)
- 🚀 **Launch Direto**: Abrir ferramentas com um clique
- 🎭 **Modal System**: Janelas elegantes para conteúdo
